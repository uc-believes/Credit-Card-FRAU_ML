Game-Theoretic SHAP Formulation

Tree SHAP allocates payout attributions φi in logit margin space:

Margin = φ0 + ∑ φi(x) → P(fraud) = σ(Margin)
φi > 0: Feature value pushes log-odds positive → strictly increases fraud probability.
φi < 0: Feature value pushes log-odds negative → supports transaction legitimacy.
Exact Additivity Guarantee: Numerical difference between native model probability and σ(φ0 + ∑φi) is verified < 10-10.
