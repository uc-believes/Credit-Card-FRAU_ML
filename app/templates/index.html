Game-Theoretic SHAP Formulation

Tree SHAP allocates payout attributions φi in logit margin space:

Margin = φ0 + ∑ φi(x) → P(fraud) = σ(Margin)
φi > 0: Feature value pushes log-odds positive → strictly increases fraud probability.
φi < 0: Feature value pushes log-odds negative → supports transaction legitimacy.
Exact Additivity Guarantee: Numerical difference between native model probability and σ(φ0 + ∑φi) is verified < 10-10.

Entity-Level Behavioral Velocity Feature Store — Enterprise Extension Blueprint
GOVERNANCE & ROADMAP

Dataset Reality Check: The Kaggle Credit Card Fraud dataset contains anonymized PCA projections (V1–V28) and lacks entity identifiers (cardholder PAN, customer ID, device fingerprint, or merchant ID). In strict accordance with enterprise data ethics, Fraud Shield refuses to fabricate fictitious card IDs.

For live core banking implementations or entity-rich benchmarks (e.g. IEEE-CIS Fraud Detection, IBM Card Transactions), the production architecture integrates an online feature store (Redis / Feast) to ingest real-time sliding-window aggregations: card_tx_count_10m, amount_ratio_to_30d_mean, impossible_travel_speed_kmh, and inter_transaction_interval_sec.
