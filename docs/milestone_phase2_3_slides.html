The High Cost of Accuracy in Fraud Detection

In our dataset of 284,807 transactions, fraud occurs in only 0.172% of cases (1 fraud per 577 legitimate transactions). A naive model unconditionally predicting "Legitimate" achieves 99.83% accuracy while catching exactly 0% of fraud. Hence, accuracy is disqualified as a primary metric.

5 Candidate Model Families
  • Dummy Baseline: Prior-stratified coin flip (establishes empirical floor).
  • Logistic Regression: L2-regularized linear baseline (C=1.0, balanced).
  • Decision Tree: Single rule-tree benchmark (depth=10, balanced).
  • Random Forest: Bagged ensemble of 200 trees (depth=15, balanced).
  • XGBoost: Gradient boosted trees with asymmetric penalization (200 trees, depth=6).
Mathematical Weighting Strategy

Scikit-learn balanced weights penalize fraud errors by class ratio:

w₁ = N / (2 · N₁) ≈ 299.71 × w₀

For XGBoost, positive gradient loss is amplified directly by training sample ratio:

scale_pos_weight = N_legit / N_fraud = 169,951 / 284 = 598.42
Model Selection Formula & Safety Gates

Operating threshold swept across [0.05, 0.95] in 100 steps on validation split to maximize:

Composite Score = 0.35 × F2 + 0.30 × PR-AUC + 0.20 × ROC-AUC + 0.15 × F1
Gate 1: Recall ≥ 70.0%
Gate 2: Precision ≥ 10.0%
Gate 3: ROC-AUC ≥ 90.0%

Tree SHAP: Game-Theoretic Mathematical Additivity

Using Shapley Additive Explanations (Tree SHAP), features act as cooperative players contributing marginal payouts to shift model prediction away from base expectation:

Margin(x) = φ₀ + ∑ φᵢ(x)  ⟹  P(fraud) = σ(φ₀ + ∑ φᵢ(x))
φᵢ > 0 (Increases Fraud Risk): Pushes logit margin positive → strictly increases fraud probability.
φᵢ < 0 (Mitigating Evidence): Pushes logit margin negative → supports transaction legitimacy.
✓ Verified in Automated Tests: Numerical difference |P(fraud) - σ(Margin)| < 10⁻¹⁰ across all transactions!
Regulatory Compliance: Attribution vs. Causality

Under GDPR Article 22 and FCRA compliance guidelines, machine learning explanations must not imply false human causation. Every explanation generated by Fraud Shield attaches an automated scientific disclaimer:

"Feature contributions indicate statistical associations learned from historical training data. They represent empirical risk signals and do NOT imply real-world causation, motive, or legal culpability."
