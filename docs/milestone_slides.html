Phase 1 · Feature Engineering
Feature Engineering & Preprocessing Pipeline
3 derived features, leakage-safe sklearn Pipeline, stratified 60/20/20 split
Derived Features — Rationale from Actual Data
log_amount
log1p(Amount)
Amount has extreme right skew. Log transform normalises distribution and handles zero-amount transactions safely.
Skewness: 16.98 · Kurtosis: 845.09
hour_of_day
(Time % 86400) / 3600
Dataset spans exactly 48 hours. Extracts cyclical time-of-day pattern. Fraud occurs earlier on average (80,747s vs 94,838s).
Range: 0.0 – 23.99 hours
is_night
1 if hour_of_day < 6
Binary flag for low-supervision window. 8.40% of all transactions occur between midnight and 6am (verified: 23,934 transactions).
Night rate verified: 8.40%

Anti-Leakage Guarantees
✓
Scaler fit on training only
Pipeline.fit() called on 170,235 training rows. Val/test use the same fitted scaler.
✓
Zero index overlap (train ∩ test = ∅)
Verified at runtime: "Leakage check passed: zero index overlap"
✓
Duplicates removed before split
1,081 duplicates dropped pre-split to prevent identical rows in train and test.
✓
SMOTE disabled by default
If enabled, SMOTE is applied only to training set after split. Config-controlled.
✓
Threshold tuned on validation set
Classification threshold is optimized on val set. Test set reserved for final report only.
✓
Inference consistency: max diff = 0.00e+00
Batch transform and single-row inference produce mathematically identical output.
